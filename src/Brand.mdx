# 브랜드 색 바꾸기

프로젝트마다 서비스 메인 색이 달라도 **색 하나만 넣으면** 버튼, 체크박스, 탭, 슬라이더, 포커스 링까지 함께 바뀌어요. 위 툴바의 "브랜드 색"에서 바로 비교해 볼 수 있어요.

## 무엇을 만들어 주나요

메인 색 하나로 라이트·다크 테마의 브랜드 토큰 6개씩(`brand`, `brand-hover`, `brand-soft`, `brand-ink`, `on-brand`, `focus`)을 만들어요.

- 버튼 글자는 **4.5:1**, 체크박스 채움과 포커스 링은 **3:1** 대비를 넘도록 맞춰요.
- 모자라면 색상은 그대로 두고 밝기만 조금 옮겨요. 조금만 진하게 하면 되는 색은 흰 글자를 유지하고, 노랑처럼 많이 진해져야 하는 색은 버튼 글자를 진한 색으로 바꿔요.
- 무엇을 바꿨는지는 `notes`로 알려 줘요.

## 쓰는 방법 세 가지

**1. React 컴포넌트 (추천, 서버 렌더링 첫 화면부터 적용)**

```tsx
// app/layout.tsx
import '@choi/ds/fonts.css';
import '@choi/ds/styles.css';
import { AppBrandStyle } from '@choi/ds';

export default function RootLayout({ children }) {
  return (
    <html lang="ko" data-theme="light">
      <head><AppBrandStyle color="#0E9888" /></head>
      <body>{children}</body>
    </html>
  );
}
```

**2. CSS 파일로 고정 (빌드할 때 한 번)**

```bash
npx choi-ds-brand "#0E9888" > src/brand.css
```

만든 `brand.css`를 앱에서 import해요. 불러오는 순서와 상관없이 기본 색보다 우선해요.

**3. 실행 중에 바꾸기 (사용자가 색을 고르는 화면 등)**

```ts
import { applyBrandTheme } from '@choi/ds';
const reset = applyBrandTheme('#2B45E0'); // reset()을 부르면 기본 색으로
```

값만 필요하면 `createBrandTheme('#0E9888')`, CSS 문자열은 `brandThemeCss('#0E9888')`예요. React 없이(서버, 스크립트) 쓰려면 `@choi/ds/brand`에서 가져와요.
